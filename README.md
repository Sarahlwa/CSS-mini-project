# Photography Sidebar Menu

A beginner-friendly mini project I created while learning CSS through **Apna College**. This project helped me practice CSS styling and build a photography-themed webpage with a sidebar navigation menu and a full-screen background image.

## Features

- Dark sidebar navigation
- Full-screen background image
- Navigation menu with icons
- Social media icons
- Simple and clean layout

## Technologies Used

- HTML5
- CSS3

## What I Learned

- Styling web pages with CSS
- Creating sidebar layouts
- Working with background images
- Positioning elements and icons
- Improving webpage appearance and layout
